# Goetia name directory

All **190** entity and name notes in this collection: **72 numbered spirits** and **118** additional figures, beings, ritual identities, or names. These are browsing records, not a claim that the book has more than 72 numbered spirits. Uncertain name relationships remain qualified on their own notes.

Alternate names appear as aliases on each note. Ritual names are explanatory glossary entries, while the contextual figures include people involved in the text’s transmission. Use [[Goetia Entity Index]] for the numbered catalogue and thematic groups.
