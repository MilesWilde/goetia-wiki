# Set

The marginalia name Set with Hadit in an elemental and numerical gloss. A later elemental annotation names the god-form Set Fighting alongside a ritual sign.

These source forms are indexed together for navigation. The note records the commentator’s associations and does not identify Set with the separately named [[Typhon Seth (Goetia)|Typhon Seth]] of the prefatory curse.
